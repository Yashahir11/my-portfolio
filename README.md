# Yash Bhetariya — Portfolio

A responsive, static portfolio built with plain HTML, CSS, and JavaScript. It can be hosted for free on Vercel without a build step.

## Run locally

Open `index.html` in a browser, or start any static file server in this folder.

## Deploy to Vercel for free

1. Create a GitHub repository and upload these project files.
2. Sign in to [Vercel](https://vercel.com/) with GitHub and choose **Add New → Project**.
3. Import the portfolio repository. Choose **Other** as the framework preset. Leave the build command, output directory, and install command empty; Vercel will serve the static files from the repository root.
4. Select **Deploy**. Vercel will publish the static site and provide a free `vercel.app` URL.

Vercel automatically redeploys when you push changes to the connected GitHub repository.
